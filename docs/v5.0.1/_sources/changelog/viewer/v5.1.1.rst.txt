v5.1.1
======

v5.1.1 brings OpenMV Viewer up to date with :doc:`OpenMV IDE 5.1.1
<../ide/v5.1.1>`. On Apple Silicon Macs every bundled tool is now a native
arm64 build, so firmware updates and recovery keep working on macOS releases
that no longer include the Intel translation layer. Nothing changes on Windows
or Linux.

.. contents:: On this page
   :backlinks: none
   :local:
   :depth: 1

What changed
------------

- **Native Apple Silicon tools** -- the flashing tools the Viewer uses for
  firmware updates, recovery, and loading a ROM file system onto the camera
  are now native arm64 builds on Apple Silicon Macs; the Intel builds failed
  on recent macOS releases
  (`36d4d9cf615 <https://github.com/openmv/qt-creator/commit/36d4d9cf615>`__).

Platform and tool support
-------------------------

- **Qt Creator base:** 14.0.2 (shared with OpenMV IDE).
- **Bundled firmware:** v5.0.1.

Breaking changes
----------------

None.
