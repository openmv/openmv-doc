v5.1.1
======

v5.1.1 is a macOS point release. Every tool OpenMV IDE runs on a Mac now ships
as a native Apple Silicon build, so firmware updates, the language server, and
the other bundled tools keep working on macOS releases that no longer include
the Intel translation layer. Nothing changes on Windows or Linux. It is built
on Qt Creator 14.0.2 and bundles firmware v5.0.1.

.. contents:: On this page
   :backlinks: none
   :local:
   :depth: 1

Highlights
----------

- **Native Apple Silicon tools** -- the bundled dfu-util, picotool, bossac,
  STM32CubeProgrammer, the NXP flashing tools, FFmpeg, the Python language
  server, and the Node.js runtime used by GitHub Copilot are now native arm64
  builds on Apple Silicon Macs. The Intel builds of these tools failed on
  recent macOS releases, which surfaced as firmware updates and other tools
  failing with errors such as "query failed"
  (`36d4d9cf615 <https://github.com/openmv/qt-creator/commit/36d4d9cf615>`__).

Platform and tool support
-------------------------

- **Qt Creator base:** 14.0.2.
- **OpenMV IDE** version bumped to 5.1.1
  (`4d038ea2d60 <https://github.com/openmv/qt-creator/commit/4d038ea2d60>`__).
- **Bundled firmware:** v5.0.1.

Breaking changes
----------------

None.
