v5.1.0#

v5.1.0 使 OpenMV Viewer 与其共享代码的 OpenMV IDE 5.1.0 保持同步。帧缓冲区下方的窗格变成了一组 实时视图——直方图加上开发板信息、内存、统计，以及显示产品脚本所发布的值和控件的全新 通道 视图——多传感器摄像头获得了 帧缓冲区源选择器，新开发板得到支持，Viewer 保留的固件和 ROM 文件系统恢复路径也经过全面审查得到加固。它基于 Qt Creator 14.0.2 构建，并捆绑固件 v5.0.1。

亮点#

  • 窗格视图——直方图窗格标题栏中的一个选择器可将窗格在 直方图、开发板信息（所连接摄像头的硬件、版本和能力）、内存（摄像头堆和内存池的实时图形）、统计（调试协议和每通道事件计数器）和 通道 视图之间切换。

  • 通道视图——当产品的脚本发布通道时，Viewer 会实时显示它们：读数和控件（标签、开关、滑块、微调框、单选按钮、单行编辑框、选择器、按钮和文本）、带频谱分析器的波形图，以及带调色板、缩放和色调映射的深度图。图形和深度图可以录制为 CSV、WAV、NumPy 或 Edge Impulse 文件，脚本停止后最后的值会保留在屏幕上。

  • 帧缓冲区源选择器——拥有多个图像传感器的摄像头会显示一个选择器，用于选择向 Viewer 流式传输的传感器，或关闭流式传输；JPG 开关变成了 JPG / RAW 流模式选择器，窗格标题会标明每一帧到达时所采用的格式。

  • 新硬件——OpenMV N6 Classic 开发板以及 FLIR Lepton 3.1R 和 UW 传感器。

变更内容#

  • 开发板信息、内存、统计和通道视图——位于直方图窗格中，已针对深色和浅色主题设计样式 (cdea506655b, 7629a588db9, 5b4f31a6b3a, dfc323b4ec7, 8c2cd6cf1f1)。

  • 帧缓冲区源选择器、流模式选择器和格式读数 (e76284bde9e, 76448d7b9dd, afece31cb6a)。

  • 直方图由完整的 8 位 RGB 计算得出，并采用共享的绘图调色板 (238e099373e, f126e8f34c0)。

  • 第三方开发板固件——与 Viewer 一同安装的供应商开发板和固件存储库会用于固件更新，包括供应商自己的开发渠道；Viewer 只安装存储库中的固件部分 (21a63a74949, b15afdac479, b04da8ee888)。

  • OpenMV N6 Classic 和 FLIR Lepton 3.1R / UW 支持 (4ff4a1f239d, bdd6c96ef47, 25fcdc13c6a, 12c03024f3c)。

  • IMX 引导加载程序交接——预先预备的捕获器会在 RT1062 的引导加载程序枚举的瞬间将其接管 (3d8b63c6859)。

  • macOS 警告——会提醒 Apple Silicon 用户注意“允许配件连接”安全设置，并在未授予输入监控权限（固件更新需要）时提醒 RT1062 用户 (742cb4d8c0b, 8890eb77834)。

  • 查看器模式快捷键——破坏查看器模式的多余快捷键已被禁用，Viewer 也不再将其已清除的快捷键写入完整 IDE 的设置中 (251b422f642, 0d153671c1d)。

错误修复#

对自 v5.0.0 以来每一项变更的两轮审查修复了（除其他外）以下适用于 Viewer 的问题 (ccea3b17d01, 71826200611)：

  • macOS 警告可能吞掉固件升级提示的“是”。

  • 摄像头的驱动器关联可能在竞争中输给其他卷，而摄像头插入超过十秒后单驱动器回退方案无法触发 (9877480c304)。

  • GENX320 事件传感器会禁用帧缓冲区；保存的传感器选择在重启后丢失。

  • 将 ROM 文件系统加载到摄像头：写入期间按 Cancel 会悄无声息地结束，留下可能不完整的 ROMFS，而 dfu-util 错误被报告为成功。现在，操作取消后会请求引导加载程序退出 DFU，使摄像头自行恢复。

  • 变砖的 N6 Classic 曾被用普通 N6 的引导加载程序和固件修复；对已处于引导加载程序模式的开发板加载自定义固件 zip 时，刷写的却是发布版本。

  • 协议检测之前执行的读取清空现在有界限（issue #336）(77cd13af76f)。

平台和工具支持#

  • Qt Creator 基础版本： 14.0.2（与 OpenMV IDE 共用）。

  • 捆绑固件： v5.0.1。

  • 新开发板与传感器： OpenMV N6 Classic；FLIR Lepton 3.1R 和 UW。

重大变更#

无。帧缓冲区标题栏中的 JPG 开关现在是 JPG Mode / RAW Mode 选择器。
