v5.1.0#

v5.1.0 นำ OpenMV Viewer ให้ทันกับ OpenMV IDE 5.1.0 ซึ่งใช้โค้ดร่วมกัน แผงใต้เฟรมบัฟเฟอร์กลายเป็นชุดของ มุมมองสด -- ฮิสโทแกรมพร้อมด้วย Board Info, Memory, Statistics และมุมมอง Channels ใหม่ที่แสดงค่าและตัวควบคุมที่สคริปต์ของผลิตภัณฑ์เผยแพร่ -- กล้องหลายเซ็นเซอร์ได้รับ ตัวเลือกแหล่งเฟรมบัฟเฟอร์ บอร์ดใหม่ได้รับการรองรับ และเส้นทางการกู้คืนเฟิร์มแวร์และระบบไฟล์ ROM ที่ Viewer เก็บไว้ได้รับการเสริมความแข็งแกร่งจากการตรวจทานเต็มรูปแบบ สร้างบน Qt Creator 14.0.2 และรวมเฟิร์มแวร์ v5.0.1 มาด้วย

จุดเด่น#

  • มุมมองของแผง -- ตัวเลือกในแถบชื่อของแผงฮิสโทแกรมสลับแผงระหว่างมุมมอง Histogram, Board Info (ฮาร์ดแวร์ เวอร์ชัน และความสามารถของกล้องที่เชื่อมต่อ), Memory (กราฟสดของฮีปและพูลหน่วยความจำของกล้อง), Statistics (ตัวนับของโปรโตคอลดีบักและตัวนับเหตุการณ์ต่อแชนเนล) และ Channels

  • มุมมอง Channels -- เมื่อสคริปต์ของผลิตภัณฑ์เผยแพร่แชนเนล Viewer จะแสดงผลแบบสด: ค่าอ่านและตัวควบคุม (ป้ายกำกับ สวิตช์สลับ แถบเลื่อน กล่องหมุนค่า ปุ่มตัวเลือก ช่องข้อความ ตัวเลือก ปุ่ม และข้อความ), กราฟรูปคลื่นพร้อมตัววิเคราะห์สเปกตรัม และแผนที่ความลึกพร้อมพาเลตต์ การปรับขนาด และการแมปโทน กราฟและแผนที่สามารถบันทึกเป็นไฟล์ CSV, WAV, NumPy หรือ Edge Impulse ได้ และค่าล่าสุดยังคงอยู่บนหน้าจอเมื่อสคริปต์หยุด

  • ตัวเลือกแหล่งเฟรมบัฟเฟอร์ -- กล้องที่มีเซ็นเซอร์ภาพมากกว่าหนึ่งตัวจะแสดงตัวเลือกเพื่อเลือกว่าเซ็นเซอร์ใดจะสตรีมไปยัง Viewer หรือปิดการสตรีม; ปุ่มสลับ JPG กลายเป็นตัวเลือกโหมดสตรีม JPG / RAW และชื่อของแผงระบุรูปแบบที่แต่ละเฟรมมาถึง

  • ฮาร์ดแวร์ใหม่ -- บอร์ด OpenMV N6 Classic และเซ็นเซอร์ FLIR Lepton 3.1R และ UW

สิ่งที่เปลี่ยนแปลง#

  • มุมมอง Board Info, Memory, Statistics และ Channels ในแผงฮิสโทแกรม จัดสไตล์สำหรับทั้งธีมมืดและธีมสว่าง (cdea506655b, 7629a588db9, 5b4f31a6b3a, dfc323b4ec7, 8c2cd6cf1f1)

  • ตัวเลือกแหล่งเฟรมบัฟเฟอร์ ตัวเลือกโหมดสตรีม และการแสดงรูปแบบ (e76284bde9e, 76448d7b9dd, afece31cb6a)

  • ฮิสโทแกรมคำนวณจาก RGB 8 บิตเต็ม พร้อมพาเลตต์พล็อตที่ใช้ร่วมกัน (238e099373e, f126e8f34c0)

  • เฟิร์มแวร์ของบอร์ดจากบุคคลที่สาม -- พื้นที่เก็บข้อมูลบอร์ดและเฟิร์มแวร์ของผู้จำหน่ายที่ติดตั้งควบคู่กับ Viewer จะถูกใช้สำหรับการอัปเดตเฟิร์มแวร์ รวมถึงแชนเนลรุ่นพัฒนาของผู้จำหน่ายเอง; Viewer ติดตั้งเฉพาะส่วนเฟิร์มแวร์ของพื้นที่เก็บข้อมูล (21a63a74949, b15afdac479, b04da8ee888)

  • รองรับ OpenMV N6 Classic และ FLIR Lepton 3.1R / UW (4ff4a1f239d, bdd6c96ef47, 25fcdc13c6a, 12c03024f3c)

  • การส่งต่อ bootloader ของ IMX -- ตัวดักจับที่เตรียมพร้อมไว้ล่วงหน้าจะยึด bootloader ของ RT1062 ทันทีที่มัน enumerate (3d8b63c6859)

  • คำเตือนบน macOS -- ผู้ใช้ Apple Silicon จะได้รับแจ้งเกี่ยวกับการตั้งค่าความปลอดภัย "Allow accessories to connect" และผู้ใช้ RT1062 จะได้รับแจ้งเมื่อไม่ได้ให้สิทธิ์ Input Monitoring (จำเป็นสำหรับการอัปเดตเฟิร์มแวร์) (742cb4d8c0b, 8890eb77834)

  • ปุ่มลัดในโหมด Viewer -- ปุ่มลัดที่หลงเหลือซึ่งทำให้โหมด viewer เสียถูกปิดใช้งาน และ Viewer ไม่เขียนปุ่มลัดที่ถูกล้างของตนลงในการตั้งค่าของ IDE แบบเต็มอีกต่อไป (251b422f642, 0d153671c1d)

การแก้ไขข้อบกพร่อง#

การตรวจทานสองรอบของทุกการเปลี่ยนแปลงตั้งแต่ v5.0.0 ได้แก้ไขสิ่งต่อไปนี้ที่มีผลกับ Viewer รวมถึงเรื่องอื่น ๆ (ccea3b17d01, 71826200611):

  • คำเตือนบน macOS อาจกลืนการตอบ "Yes" ของข้อความแจ้งอัปเกรดเฟิร์มแวร์

  • การจับคู่ไดรฟ์ของกล้องอาจแพ้การแข่งขันกับโวลุมอื่น และทางสำรองแบบไดรฟ์เดียวไม่สามารถเข้าถึงได้เมื่อกล้องเสียบอยู่นานกว่าสิบวินาที (9877480c304)

  • เซ็นเซอร์เหตุการณ์ GENX320 ปิดเฟรมบัฟเฟอร์; การเลือกเซ็นเซอร์ที่บันทึกไว้ไม่คงอยู่หลังรีสตาร์ท

  • การโหลดระบบไฟล์ ROM ลงในกล้อง: Cancel ระหว่างการเขียนจบลงเงียบ ๆ โดย ROMFS อาจถูกเขียนไม่ครบ และข้อผิดพลาดของ dfu-util ถูกรายงานว่าสำเร็จ ตอนนี้ bootloader จะถูกขอให้ออกจาก DFU หลังจากการดำเนินการที่ถูกยกเลิก เพื่อให้กล้องกลับมาเองได้

  • N6 Classic ที่บริกถูกซ่อมด้วย bootloader และเฟิร์มแวร์ของ N6 ธรรมดา; ไฟล์ zip เฟิร์มแวร์แบบกำหนดเองบนบอร์ดที่อยู่ในโหมด bootloader อยู่แล้วกลับแฟลชบิลด์รุ่นปล่อยแทน

  • การล้างบัฟเฟอร์อ่านที่รันก่อนการตรวจจับโปรโตคอลมีขอบเขตจำกัดแล้ว (issue #336) (77cd13af76f)

การรองรับแพลตฟอร์มและเครื่องมือ#

  • ฐาน Qt Creator: 14.0.2 (ใช้ร่วมกับ OpenMV IDE)

  • เฟิร์มแวร์ที่รวมมา: v5.0.1

  • บอร์ดและเซ็นเซอร์ใหม่: OpenMV N6 Classic; FLIR Lepton 3.1R และ UW

การเปลี่ยนแปลงที่ทำให้เข้ากันไม่ได้#

ไม่มี ปุ่มสลับ JPG ในแถบชื่อของเฟรมบัฟเฟอร์ตอนนี้เป็นตัวเลือก JPG Mode / RAW Mode
