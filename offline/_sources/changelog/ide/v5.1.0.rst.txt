v5.1.0
======

v5.1.0 is a feature release. The pane under the frame buffer grows from a
histogram into a set of **live views** -- Board Info, Memory, Statistics, and
the new **Channels** view that turns the values a script publishes into
widgets, graphs, spectra, and depth maps and records them to files -- the
frame buffer gets a **source selector** for multi-sensor cameras, the IDE
learns to load **third-party repositories** of boards, firmware, examples,
models, and stubs, and video recordings switch to H.264. New boards and
sensors are supported, the firmware tooling was hardened by a full audit of
every change since v5.0.0, and a handful of behaviours were brought over from
OpenMV Studio. It is built on Qt Creator 14.0.2 and bundles firmware v5.0.1.

Highlights
----------

- **Pane views** -- the histogram pane's title bar gains a selector that
  switches the pane between the **Histogram**, **Board Info** (the connected
  camera's hardware, versions, and capabilities), **Memory** (live graphs of
  the MicroPython heap and every UMA pool, with peak tracking), **Statistics**
  (the debug protocol's packet, error, and per-channel event counters), and
  **Channels** views.
- **Channels view** -- a script can publish named channels of data and
  controls over the debug protocol, and the IDE renders them live: labels,
  toggles, sliders, spin boxes, radio buttons, line edits, selectors, push
  buttons, and text blocks that write back to the camera; waveform graphs
  with pan, zoom, markers, triggers, history, and a spectrum analyzer; and
  depth maps with the camera's own palettes, three scaling filters, and tone
  mapping. Any graph or map records to CSV, WAV, NumPy, or Edge Impulse JSON
  and CBOR files -- including a Record All for a whole channel -- for training
  data collection. The last values stay on screen when a script stops.
- **Frame buffer source selector** -- cameras with more than one image sensor
  show a selector in the frame buffer's title bar to choose which sensor
  streams to the IDE (or to turn streaming off), the JPG toggle became a
  JPG / RAW streaming-mode selector, and the pane's title names the format
  each frame arrived in.
- **Third-party repositories** -- a vendor can publish a repository of boards,
  firmware (release and development channels), examples, machine-learning
  models, and ``.pyi`` stubs; the IDE installs it from a URL or from a folder
  an installer dropped in, merges it with its own content, keeps it updated,
  and lets you order vendors by priority. Managed from Preferences → OpenMV →
  Third Party Repositories.
- **New hardware** -- the OpenMV N6 Classic board (including its bootloader
  driver, udev rule, and ROM-DFU recovery entry) and the FLIR Lepton 3.1R and
  UW sensors.
- **H.264 recordings** -- the frame buffer recorder and the video converter
  now encode H.264 instead of MPEG-4 Part 2, with a pinned key-frame interval
  so recordings seek cleanly and the frame rate snapped to a whole number.
- **Audit fixes** -- every commit since v5.0.0 was reviewed twice for
  regressions, with particular attention to the firmware, bootloader, and
  ROMFS paths; the defects found are fixed in this release (see
  :ref:`bug fixes <v5_1_0_bug_fixes>`).

Editor, terminal, and UI improvements
--------------------------------------

- **Histograms are computed from full 8-bit RGB** instead of the camera's
  RGB565 tables, with a shared plot palette, alpha-blended fills, and dimmer
  grid lines
  (`238e099373e <https://github.com/openmv/qt-creator/commit/238e099373e>`__,
  `f126e8f34c0 <https://github.com/openmv/qt-creator/commit/f126e8f34c0>`__,
  `cebbf0c9e2c <https://github.com/openmv/qt-creator/commit/cebbf0c9e2c>`__).
- **Hidden pane views do no work** -- the histogram skips its computation and
  replots while another view is showing or the pane is collapsed, and catches
  up when shown again; zero-size replots are silenced
  (`c8730df8399 <https://github.com/openmv/qt-creator/commit/c8730df8399>`__).
- **Example scripts open with a blank line after the imports**, and the
  bundled examples were reformatted the same way

  (`c4279c0213e <https://github.com/openmv/qt-creator/commit/c4279c0213e>`__).

Bug fixes
---------

Two review passes over every change since v5.0.0 found and fixed the following
(`ccea3b17d01 <https://github.com/openmv/qt-creator/commit/ccea3b17d01>`__,
`71826200611 <https://github.com/openmv/qt-creator/commit/71826200611>`__):

- **Firmware and bootloader paths** -- a Load Custom Firmware zip onto a board
  already in bootloader mode flashed the release build instead; the Alif
  recovery path now refuses a custom build rather than flashing the release;
  a bricked N6 Classic was repaired with the plain N6 bootloader and
  firmware; a stale third-party resource root could steer a bricked built-in
  board to vendor files; the IMX catcher could proceed to flash after it
  crashed, ignored Cancel while waiting for the flashloader, and left the
  serial port open after a cancel during arming; the N6 Classic bootloader
  had no udev rule; the Windows driver installer's accepted exit codes had a
  typo.
- **ROMFS editor** -- Cancel during a ROMFS read reported "Failed to unpack
  ROMFS!" and waited ten seconds for a camera still in the bootloader; Cancel
  during a write ended silently with a possibly partial ROMFS; a dfu-util
  error during a write was reported as success; Cancel in the follow-up
  dialog discarded every edit; Auto Reconnect could connect underneath the
  open editor; Edit ROMFS while connected needlessly disconnected and
  reconnected first; converter temp directories leaked. After a cancelled
  operation the bootloader is now asked to leave DFU so the camera comes
  back on its own.
- **Third-party repositories** -- zip entries are validated before extraction
  (no path traversal or symlinks), part installs and reinstalls keep the old
  copy until the new one is in place, a rejected vendor board no longer takes
  the built-in board it overlapped down with it, a missing PID mask matched
  nothing at runtime, and base example / model index rows no longer capture
  same-named vendor files.
- **Frame buffer and sensors** -- the GENX320 event sensor (chip id above
  ``0x80000000``) disabled the frame buffer; a saved sensor selection did not
  survive a restart; the old "disable frame buffer" preference was not
  migrated; the stream-source command is gated on the protocol version; the
  focus metric froze while the histogram page was hidden; the frame format
  lingered in the title after disconnect.
- **Connect flow** -- the macOS warnings could swallow the "Yes" of the
  firmware-upgrade prompt; the Model Zoo always opened collapsed with no
  selection restored; the single-drive fallback for the camera's drive was
  unreachable when the camera had been plugged in for more than ten seconds.
- **Channels view and recorder** -- hostile frame sizes could overflow the
  size checks; the Edge Impulse recorders reallocated on every chunk and are
  now capped at 64 MB per part; a schema with separators in names could index
  past the record list; duplicate records orphaned a running recorder; writes
  are dropped while the view is frozen; the channel list now refreshes on
  unregister and soft-reboot events.
- **Video** -- an odd user-entered width broke H.264 encoding on the libx264
  builds; cancelled or failed ``.bin`` conversions left frames that the next
  run folded in.
- **Protocol** -- the read flush that runs before protocol detection is bounded
  (issue #336)
  (`77cd13af76f <https://github.com/openmv/qt-creator/commit/77cd13af76f>`__);
  the camera-drive association no longer loses the race to other volumes
  (`9877480c304 <https://github.com/openmv/qt-creator/commit/9877480c304>`__).
- A ``-Wdeprecated-copy`` warning in the serial port info wrapper
  (`abcfaa8af5e <https://github.com/openmv/qt-creator/commit/abcfaa8af5e>`__).

Platform and tool support
-------------------------

- **Qt Creator base:** 14.0.2.
- **OpenMV IDE** version bumped to 5.1.0.
- **Bundled firmware:** v5.0.1 (see the :doc:`firmware changelog
  <../firmware/v5.0.1>`).
- **New boards and sensors:** OpenMV N6 Classic; FLIR Lepton 3.1R and UW.

Breaking changes
----------------

None for existing projects. The JPG toggle in the frame buffer's title bar is
now a JPG Mode / RAW Mode selector, and its old "disable frame buffer" setting
is migrated into the new source selector's Off entry. Comments are stripped
from scripts before they run; a script that relies on reading its own source
text at runtime should not.
